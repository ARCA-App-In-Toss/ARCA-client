# 사용자 검토 패킷

이미 모인 결과를 5~8개 항목 안에서 정리한다. 없는 항목을 채우려고 명세/코드를 다시 탐색하지 않는다.

- 범위·결과: 단계/작업 ID와 사용자가 할 수 있게 된 일.
- 변경: 핵심 파일 링크, 채택한 선택과 담당 명세 위치. 필요하면 commit/dirty.
- 검증: 실제 실행한 명령·핵심 테스트 ID·결과와 리뷰 파일 링크. 동일 결과를 본문과 표로 반복하지 않는다.
- 미확인: 현재 판단에 필요한 BLOCKED/NOT_RUN과 실제 환경 증거만 표시한다. Mock 성공·단계 완료·출시 가능을 구분한다.
- 다음 행동: 남은 작업 또는 사용자가 결정할 사항 하나와 추천안. 이미 승인/위임된 일에 다시 승인을 요구하지 않는다.

성공 로그·전체 diff·스크린샷은 기본 첨부하지 않는다. 실패 재현이나 시각 채택에 필요한 안전한 증거만 연결한다. 전체 단계가 아직 끝나지 않았으면 부분 진행이라고 명시한다.
